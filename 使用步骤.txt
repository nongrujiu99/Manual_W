说明书编辑器 v3.0.3 · 使用步骤
================================================

【想发给别人 / 换台电脑用】
直接发这个链接：
    https://nongrujiu99.github.io/Manual_W/
对方用 Chrome / Edge 打开就能用，不用下载、不用安装。

· 在线版反而能直接用 AI：浏览器在 https 下允许跨域，
  不必开本地代理；只有本地双击打开时才需要代理。
· 资料存在各自浏览器里，不会上传到任何服务器。
  换设备或清缓存前，先「导出 → 工程备份 .json」，
  下次「导入工程」即可恢复。
· 在线版和本地版的数据不互通（浏览器按域名分开存）。

【正常情况：只需要 2 步】

1) 双击  说明书编辑器-v2.html
   用 Chrome / Edge 打开（不要用 IE）。

2) 右上角「引擎与设置」
   · 填入你的 API Key（sk- 开头）
   · 模型选  qwen-flash（最快 · 推荐）
   · 勾选  「快速模式」（默认已勾选）
   · 点「测试连接」→ 显示「连接成功 ✅」
   · 点「完成」

3) 导入文档 → 点「✨ AI 智能整理」

【完全不想用 AI】
   导入文档后直接点「⚡ 本地自动排版」：
   不联网、不用 Key、不用任何配置，照样出杂志式排版。

------------------------------------------------
界面分工：左中右三栏 —— 找 → 改 → 看
------------------------------------------------
左栏（找）
  · 最上面固定「文档」：标题、语言版本、章/块/图数量、AI 翻译。
    不管在改哪一章，都看得到、改得到。
  · ① 内容来源（点标题展开）：导入文档 / 粘贴文本 / 本地排版 / AI 整理
        + 原文框，改完原文再点自动排版。
  · ② 章节：只列章节，不列里面的内容块。
       每条后面是本章的块数；第一个章节之前的「开篇内容」也单列一条。
       单击 → 中间展开本章全部内容
       拖动 → 整章换顺序；✕ → 删整章
       列表最底下一条虚线「＋ 新增章节」→ 在文档末尾新建一章（滚动时
       会贴在栏底，随时点得到）。章里加段落、列表、图片这些不在这儿，
       统一在中间那一栏的本章末尾加，不设第二个入口。
  · 图片不再单独占一个面板：图属于哪一章，就在那一章的末尾直接加 / 删，
    不用在两个面板之间来回找。

中间（改）
  · 「编辑」：选中一个章节，这里从上到下就是本章的全部内容 ——
    先章标题，再一块接一块的卡片，每个字段都能就地改，改一个字立刻生效。
      标题 / 正文 → 直接改文字
      列表 / 步骤 → 一行一条
      参数表     → 一行一条，用 | 分列（「参数：值」也认）
      图片       → 点缩略图上传 / 更换、图注、版式
      图集       → 版式 + 每张图的缩略图、图注、删除
    每张卡片右上角：↑ ↓ 在本章内换位置，⧉ 复制，✕ 删除；
    左上角下拉可直接把这块换成别的类型。
    本章末尾是一条「＋ 新增内容」，和左栏那条一个长相 —— 点开浮出六种类型
    （文字段落 / 小节标题 / 要点列表 / 参数表格 / 单张图片 / 图片图集），
    选哪个就在本章末尾加哪种，加完直接把光标放进新卡片；点空白或按 Esc 收起。
    这是全篇唯一的「加内容」入口，不再满屏都是加号按钮。
    最底下是 本章上移 / 下移 / 删除本章；顶部 ‹ › 按章节前后翻。
  · 「整本外观」：常驻这一栏底部的一条，点一下从底部浮起 ——
    主题配色、品牌主色、排版密度、封面风格。再点一下或按 Esc 收起，
    展开时是浮层，不会把上面的编辑内容挤没了。

右边（看）
  · 只有预览，整块空间都留给手机，不再和编辑面板抢地方。
  · 预览条上两组开关：
      只看本章 / 整篇   默认「只看本章」：左栏点哪章，手机里就是哪章
      手机 / 平板 / 宽屏
  · 「只看本章」时，手机顶部有一条章节条：编号 · 章节名 · 块数 · 看整篇。
    想回到完整文档（含封面、目录），点「看整篇 ›」或把上面切到「整篇」。
  · 「整篇」时点左栏章节，会自动滚到该章开头并标出整章范围。
  · 在预览里单击某一块，只是把它定位到中间那一栏对应的卡片上 ——
    不会再弹出一排「↑ ↓ 编辑 类型 删除」的浮动工具条，预览始终是干净的成品样子。
    要移动、改类型、删除，都用中间那张卡片右上角的小按钮。
  · 双击文字 → 就地改；双击图片 → 放大；Esc 或点空白关闭大图。

两个小规矩，省心：
  · 插入新板块后直接就能打字；如果什么都没填就切走，这一块会自动
    撤掉，不会在文里留个空壳。
  · 每一处改动都能 Ctrl+Z 退回；一次连续输入算一步，不会退一个字一步。

------------------------------------------------
v3.0.3 新增（这次是「预览不再挂工具条」）
------------------------------------------------
· 取消预览窗口里的浮动工具条（↑ ↓ / ✎ 编辑 / 类型下拉 / 删除）。
  预览里点一块，只做两件事：滚到那一块、把中间那一栏定位到对应卡片。
· 移动、换类型、删除、复制、换图、改图注，全部在中间栏的卡片右上角完成，
  不再有两套按钮做同一件事 —— 预览里看到的永远是成品原样，不会被工具遮挡。
· 因此预览里的「↑ ↓ 编辑 段落 删除」那一排已经彻底移除，点哪里都不会再冒出来。

------------------------------------------------
v3.0.2 新增（这次改的是「加内容」只留一个入口）
------------------------------------------------
· 中间那一栏末尾原来铺着 6 个「＋ 文字 / 小节 / 列表 / 参数表 / 图片 / 图集」按钮，
  现在合并成一条「＋ 新增内容」，样式、宽度都跟左栏的「＋ 新增章节」一样。
· 点它，按钮上方浮出一张小白卡，六种类型两列排开，选完立刻收起来并把新卡片
  调到眼前。上方空间不够时自动翻到按钮下方，箭头始终指向按钮。
· 好处：加内容不再占掉半屏，正文能多看两页；也看不出「哪几个是重点」的偏袒感。
· 顺手：撤销后如果原来那块已经没了，会自动落到第一章，不会三栏一起空掉。

------------------------------------------------
v3.0 新增（这次改的是「布局」：找、改、看各占一栏）
------------------------------------------------
· 三栏重排：左栏找（文档 / 内容来源 / 章节）→ 中间改（本章内容 + 整本外观）
  → 右边看（只有预览）。原来编辑面板和预览挤在一起，现在预览独占一整栏。
· 「图片」面板取消：图片是章节内容的一部分，在章节末尾点「＋ 图片」
  「＋ 图集」直接加，卡片里点缩略图换图、✕ 删除。不再有第二处图片清单。
· 「整本外观」独立成一条常驻面板，钉在编辑栏底部，点开是浮层，
  调色 / 密度 / 封面时不会把正文编辑区挤扁。
· 预览加了「只看本章 / 整篇」开关（默认只看本章）：
  左栏点哪章，手机里就是那一章，顶部还有章节条（编号 · 名称 · 块数）。
  想核对封面、目录、整本节奏，切「整篇」即可，仍是完整文档。
· 打开就有内容时，自动选中第一章，不用先点一下才看到东西。
· 快捷键：Alt+↑ / Alt+↓ 按章节前后翻；Esc 收起外观面板 / 关大图 / 关弹窗。

v2.4 新增（这次改的是「章节面板只放章节」）
------------------------------------------------
· 左栏「章节」只列章节标题，不再把章节里的段落、列表、图片一条条铺出来。

· 章节名、块数、顺序都会即时同步：改章标题，左栏和预览同时变；拖左栏整章挪位，

------------------------------------------------
AI 很慢 / 卡住不动，怎么办
------------------------------------------------
原因几乎都是：模型在"深度思考"，会先想一大段再输出。
按顺序试：

① 模型换成 qwen-flash，并确认「快速模式」是勾选的
   （快速模式会发送 enable_thinking=false，通常快 3~10 倍）
② 原文太长：先只贴一部分试试，确认能跑通再全量
③ 实在不行就点「⚡ 本地自动排版」，不联网照样出稿

------------------------------------------------
关于「AI本地代理」（大多数情况用不到）
------------------------------------------------
只有在你确认「测试连接」报的是网络错误（不是 Key 无效）时，
才需要它。启动方式：
   Windows：双击  启动AI代理.bat
   macOS  ：双击  启动AI代理.command
然后把接口地址改成 http://127.0.0.1:8787/v1
（设置里有「填入本机代理地址」按钮，点一下即可）

没装 Python 的话双击启动器会没反应 —— 这种情况下直接用上面的
「本地自动排版」，或者先点「测试连接」看看是否其实能连通。

------------------------------------------------
其它常见问题
------------------------------------------------
· 图片不准是正常的：在任意章节末尾点「＋ 图片 / ＋ 图集」就能加，
  卡片里点缩略图即可上传 / 更换，图集里的单张图也能单独换 / 删 / 改图注；
  纯文本资料也会自动留好占位图，点一下就能上传。
· 端口 8787 被占用（仅用代理时）：
      python3 AI本地代理.py --port 8899
  接口改成 http://127.0.0.1:8899/v1
· 浏览器提示"内容过大无法自动保存"：
  图太多，超出 localStorage 上限。点「导出 → 工程备份 .json」，
  下次「导入工程」即可恢复，不会丢。
· 想备份：点右上「导出 → 单页 HTML」，得到单个文件可随时打开。

------------------------------------------------
安全说明
------------------------------------------------
· Key 只存在你本机浏览器里，不会上传到任何第三方。
· 代理（若使用）只监听 127.0.0.1，外网访问不到你的电脑，
  也不保存、不记录你的 Key 内容。
· 如果 Key 曾在聊天/群里明文发过，建议去控制台重新生成一个。

------------------------------------------------
改代码的人看这里：源码与产物
------------------------------------------------
根目录的「说明书编辑器-v2.html」是产物，不要直接改它。
它约 2.2 MB，其中 92% 是内嵌的第三方库：
  · PDF.js 主库        312 KB
  · PDF.js worker     1.06 MB（以 Blob 方式启动，存为 JS 字符串）
  · mammoth           628 KB（Word 解析）
手写的 HTML/CSS/JS 只有约 200 KB。

真正的源码在 src/ 和 vendor/：
  src/editor.src.html     手写的 HTML/CSS/JS，含 3 处占位
                          /* @vendor:文件名 */
                          "@@vendor-json:文件名@@"
  vendor/pdfjs.js         PDF.js（Apache-2.0）
  vendor/pdfjs.worker.js  PDF.js worker
  vendor/mammoth.js       mammoth
  build.py                把上面几样合并回单文件

改完源码后跑一次打包，任选其一：
  · 双击 构建单文件.bat      （Windows）
  · 双击 构建单文件.command  （macOS）
  · 命令行 python build.py
只校验、不写文件： python build.py --check

打包全程不做换行符转换，产物与拆分前的单文件逐字节一致
（sha256 相同），所以「单文件、离线可用、无外部依赖」没有改变。
要升级第三方库，直接替换 vendor/ 里对应文件再打包即可，
不用动 src/editor.src.html。
